# Flag Battle: ваш ключ YouTube API

Режим стримера читає чат вашої трансляції через YouTube Data API. Без ключа доступна проба 5 хвилин на день, а з власним безкоштовним ключем можна вести трансляцію годинами. Це займе близько 5 хвилин.

## 1. Відкрийте Google Cloud

Перейдіть на [console.cloud.google.com](https://console.cloud.google.com/) і увійдіть будь-яким обліковим записом Google (не обов'язково обліковим записом каналу). Якщо попросять, прийміть умови. Банківська картка не потрібна.

## 2. Створіть проєкт

Угорі сторінки натисніть вибір проєкту (**Select a project**), потім **New project**. Назва будь-яка, наприклад `flag-battle`. Натисніть **Create** і перевірте, що вгорі вибрано новий проєкт — усе подальше робиться в ньому.

## 3. Увімкніть YouTube Data API v3 — до створення ключа

Відкрийте [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) і натисніть **Enable**. API увімкнено, коли кнопка змінилася на **Manage**. Без цього кроку ключ не працюватиме.

## 4. Створіть ключ

Відкрийте [Credentials](https://console.cloud.google.com/apis/credentials) → **Create credentials** → **API key**. У списку обмежень API позначте лише **YouTube Data API v3** і натисніть **Create**. У вікні **API key created** буде ваш ключ — скопіюйте його.

Якщо YouTube Data API v3 у списку немає, поверніться до кроку 3. Обмеження застосунку залиште **None**.

## 5. Вставте ключ у застосунок

У Flag Battle: головний екран → **Налаштування** → режим **Дуель** → **Режим стримера** → **Увімк**. Натисніть кнопку вставлення біля поля **Твій ключ YouTube API v3** — не в поле тексту підказки під ним. Ключ зберігається лише на вашому телефоні, у захищеному сховищі, і ніколи не показується на екрані.

## Якщо ключ відхилено

Причину видно в блоці **ДАЛІ**:

- **«для ключа не ввімкнено YouTube Data API v3»** — виконайте крок 3 у тому ж проєкті, де створено ключ, і зачекайте кілька хвилин.
- **«обмеження ключа не пускають YouTube»** — відкрийте ключ у [Credentials](https://console.cloud.google.com/apis/credentials): в обмеженнях API має бути **YouTube Data API v3**, обмеження застосунку — **None**.
- **«ключ YouTube недійсний»** — ключ скопійовано не повністю: він починається з `AIza` і має 39 символів.

Після виправлення вийдіть у меню й знову запустіть ефір.

## Корисно знати

- **Це безкоштовно.** Стандартна квота — 10 000 одиниць на день. У режимі «Миттєво» повідомлення чату надходять одразу, і квоти вистачає приблизно на 6 годин трансляції на день; режим «Економно» розтягує її приблизно до 12 годин, із затримкою до 10 секунд. Режим вибирається в застосунку.
- **Квота оновлюється опівночі за тихоокеанським часом.** Якщо вона закінчиться, застосунок покаже це в блоці **ДАЛІ**, а бої триватимуть із випадковими прапорами.
- Використовуйте проєкт лише для Flag Battle, щоб квоту не витрачало щось інше.
- Щоб відкликати ключ, видаліть його в [Credentials](https://console.cloud.google.com/apis/credentials).
