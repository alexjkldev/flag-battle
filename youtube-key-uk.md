# Flag Battle: ваш ключ YouTube API

Режим стримера читає чат вашої трансляції через YouTube Data API. Без ключа доступна проба 5 хвилин на день, а з власним безкоштовним ключем можна вести трансляцію годинами. Це займе близько 5 хвилин.

## 1. Відкрийте Google Cloud

Перейдіть на [console.cloud.google.com](https://console.cloud.google.com/) і увійдіть будь-яким обліковим записом Google (не обов'язково обліковим записом каналу). Якщо попросять, прийміть умови. Банківська картка не потрібна.

## 2. Створіть проєкт

Угорі сторінки натисніть на вибір проєкту (**Select a project**), потім **New project**. Назва будь-яка, наприклад `flag-battle`. Натисніть **Create** і перевірте, що вгорі вибрано новий проєкт.

## 3. Увімкніть YouTube Data API

Відкрийте [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) і натисніть **Enable**.

## 4. Створіть ключ

Відкрийте [Credentials](https://console.cloud.google.com/apis/credentials), натисніть **Create credentials** → **API key**. Відкрийте новий ключ для редагування:

- **API restrictions** → **Restrict key** → позначте лише **YouTube Data API v3**. Тоді ключ, що витік, не можна буде використати ні для чого іншого.
- **Application restrictions** можна залишити **None**.

Натисніть **Save** і скопіюйте ключ (**Show key** → скопіювати).

## 5. Вставте ключ у застосунок

У Flag Battle відкрийте **Налаштування → Дуель → Режим стримера** і натисніть кнопку вставлення поруч із полем ключа YouTube API. Ключ зберігається лише на вашому телефоні, у захищеному сховищі, і ніколи не показується на екрані.

## Корисно знати

- **Це безкоштовно.** Стандартна квота — 10 000 одиниць на день. Якщо опитувати чат раз на 8 секунд, її вистачає приблизно на 4,4 години трансляції на день (раз на 5 с — близько 2,8 год, раз на 10 с — близько 5,6 год); інтервал вибирається в застосунку.
- **Квота оновлюється опівночі за тихоокеанським часом.** Якщо вона закінчиться, застосунок покаже це в блоці **ДАЛІ**, а бої триватимуть із випадковими прапорами.
- Використовуйте проєкт лише для Flag Battle, щоб квоту не витрачало щось інше.
- Щоб відкликати ключ, видаліть його в [Credentials](https://console.cloud.google.com/apis/credentials).
