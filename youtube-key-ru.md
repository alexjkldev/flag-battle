# Flag Battle: ваш ключ YouTube API

Режим стримера читает чат вашего эфира через YouTube Data API. Без ключа доступна проба 5 минут в день, а со своим бесплатным ключом можно вести эфир часами. Это займёт около 5 минут.

## 1. Откройте Google Cloud

Перейдите на [console.cloud.google.com](https://console.cloud.google.com/) и войдите любым аккаунтом Google (не обязательно аккаунтом канала). Если попросят, примите условия. Банковская карта не нужна.

## 2. Создайте проект

Вверху страницы нажмите на выбор проекта (**Select a project**), затем **New project**. Название любое, например `flag-battle`. Нажмите **Create** и проверьте, что вверху выбран новый проект — всё дальнейшее делается в нём.

## 3. Включите YouTube Data API v3 — до создания ключа

Откройте [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) и нажмите **Enable**. API включён, когда кнопка сменилась на **Manage**. Без этого шага ключ работать не будет.

## 4. Создайте ключ

Откройте [Credentials](https://console.cloud.google.com/apis/credentials) → **Create credentials** → **API key**. В списке ограничений API отметьте только **YouTube Data API v3** и нажмите **Create**. В окне **API key created** будет ваш ключ — скопируйте его.

Если YouTube Data API v3 в списке нет, вернитесь к шагу 3. Ограничения приложения оставьте **None**.

## 5. Вставьте ключ в приложение

В Flag Battle: главный экран → **Настройки** → режим **Дуэль** → **Режим стримера** → **Вкл**. Нажмите кнопку вставки рядом с полем **Твой ключ YouTube API v3** — не в поле текста подсказки под ним. Ключ хранится только на вашем телефоне, в защищённом хранилище, и никогда не показывается на экране.

## Если ключ отклонён

Причина видна в блоке **ДАЛЕЕ**:

- **«для ключа не включён YouTube Data API v3»** — выполните шаг 3 в том же проекте, где создан ключ, и подождите несколько минут.
- **«ограничения ключа не пускают YouTube»** — откройте ключ в [Credentials](https://console.cloud.google.com/apis/credentials): в ограничениях API должен быть **YouTube Data API v3**, ограничения приложения — **None**.
- **«ключ YouTube неверный»** — ключ скопирован не целиком: он начинается с `AIza` и длиной 39 символов.

После исправления выйдите в меню и снова запустите эфир.

## Полезно знать

- **Это бесплатно.** Стандартная квота — 10 000 единиц в день. В режиме «Мгновенно» сообщения чата приходят сразу, и квоты хватает примерно на 6 часов эфира в день; режим «Экономно» растягивает её примерно до 12 часов, с задержкой до 10 секунд. Режим выбирается в приложении.
- **Квота обновляется в полночь по тихоокеанскому времени.** Если она закончится, приложение покажет это в блоке **ДАЛЕЕ**, а бои продолжатся со случайными флагами.
- Используйте проект только для Flag Battle, чтобы квоту не тратило что-то ещё.
- Чтобы отозвать ключ, удалите его в [Credentials](https://console.cloud.google.com/apis/credentials).
